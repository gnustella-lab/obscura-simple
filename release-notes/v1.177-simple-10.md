# Obscura Simple UI 1.177-10

This release refreshes Simple UI with the official app's visual style while retaining the existing VPN controls and validated Linux kill switch.

## What's changed

- Redesigned Connection, Location, Account, Settings, Help, and About with gray surfaces, orange controls, blue sidebar selection, and official artwork.
- Integrated the native GTK sidebar without duplicating navigation inside the web view. Browser previews use a matching fallback sidebar.
- Moved the pixel grid into the Connection page background. Clicking Connect starts an immediate bottom-to-top orange fill, with cancellation, failure handling, and reduced-motion support.
- Added a connection protection panel and location status banner that distinguish VPN protection, kill-switch blocking, and unconfirmed firewall status.
- Updated location rows, search, favorites, and keyboard activation. Restored the previous SVG flag proportions, rounded corners, and thin borders.
- Corrected dark-theme button text and the Quick Connect lightning icon. The orange button color now matches light mode.
- Refreshed account controls, appearance settings, help links, and the About screen. Update checks open this repository's latest release page.
- Updated the Debian package and executable version strings to `1.177-10`.

## Validation

UI checks cover all six screens, light/dark themes, narrow layouts, navigation, search, pinning, keyboard connection, account-number masking, protection states, and pixel animation behavior. GTK integration and its sidebar CSS were also checked.

The Linux kill switch backend is unchanged from `1.177-9`. Its prior boot and lifecycle validation is documented in [the boot fix report](https://github.com/gnustella-lab/obscura-simple/blob/v1.177-simple-10/KILL_SWITCH_BOOT_FIX_REPORT.md).

## Installation or upgrade

Download `obscura-simple_1.177-10_amd64.deb` and `SHA256SUMS` from this release:

```sh
sha256sum -c SHA256SUMS
sudo apt install ./obscura-simple_1.177-10_amd64.deb
```

Close and reopen the GUI after upgrading if it was already running, so its version matches the upgraded service. Package architecture: **amd64**, with dependencies targeting Ubuntu 24.04 or a compatible system. No account credentials are included.
