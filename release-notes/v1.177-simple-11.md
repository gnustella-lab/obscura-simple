# Obscura Simple UI 1.177-11

This release improves location browsing and fixes the Connection background animation and location picker outline.

## What's changed

- Added expandable country sublists in both Connection and Location. Search reveals matching cities, and country expansion is preserved across status updates.
- Kept last-chosen and pinned locations available as shortcuts.
- Fixed the location picker focus outline to include the country flag and the entire control. Added Escape, outside-click, and keyboard focus dismissal.
- Made orange background pixels reveal row by row from bottom to top, including fast connections and returning to the Connection screen.
- Added **Settings → Appearance → Connection background animation** with **Follow system preference**, **Animate bottom to top**, and **No animation**. The preference is saved locally. The default respects reduced motion; choose **Animate bottom to top** to enable this effect when desktop animations are disabled.
- Updated package and executable versions to `1.177-11` and refreshed the documentation and previews.

## Validation

Automated UI tests passed. Isolated browser checks with sample data covered country grouping, search, selection without connecting, keyboard focus, Escape, mobile bounds, measured bottom-to-top opacity progression, cancellation, fast connections, and preference persistence. These checks did not initiate a real VPN connection.

The VPN backend and Linux kill switch are unchanged from the previous release.

## Installation or upgrade

Download `obscura-simple_1.177-11_amd64.deb` and `SHA256SUMS` from this release:

```sh
sha256sum -c SHA256SUMS
sudo apt install ./obscura-simple_1.177-11_amd64.deb
```

Close and reopen the GUI after upgrading. Package architecture: **amd64**, with dependencies targeting Ubuntu 24.04 or a compatible system.
