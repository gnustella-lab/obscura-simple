# Obscura Simple UI 1.177-12

This release brings the native GTK 4 / WebKitGTK interface closer to the official Obscura design.

## What's changed

- Harmonized native and web sidebar colors, blue selection, orange accents, and spacing.
- Refined Connection typography, Quick Connect styling, the city connection button, and traffic indicator.
- Displayed city cards directly under region headings in Location, retaining search, last-chosen and pinned shortcuts. The Connection picker retains expandable country groups.
- Added accessible reveal/copy account icons and refined account panels.
- Added social icons to Help and adjusted responsive layouts for native and narrow windows.
- Updated package and executable versions to `1.177-12`.

## Validation

- All 12 existing JavaScript tests passed, including kill-switch status and pixel animation checks.
- JavaScript syntax and native GTK CSS parsing passed.
- WebKit rendering checks covered all six screens, regional city cards, account visibility controls, and the kill-switch blocked state in desktop, native-pane, and narrow layouts using sample data.

The VPN backend and Linux kill switch retain their existing behavior. UI protection messages continue to use acknowledged firewall status. Rendering checks did not initiate a real VPN connection.

## Installation or upgrade

Download `obscura-simple_1.177-12_amd64.deb` and `SHA256SUMS`:

```sh
sha256sum -c SHA256SUMS
sudo apt install ./obscura-simple_1.177-12_amd64.deb
```

Close and reopen the GUI after upgrading. Package architecture: **amd64**, targeting Ubuntu 24.04 or a system with compatible dependencies.
