# Obscura Simple UI 1.177-13

## What's changed

- Removed spacing, outer padding, and rounded corners from the animated Connection background pixels, including narrow layouts.
- Orange buttons now use white text in both light and dark themes. Quick Connect icons are also white in both themes.
- The city Connect button uses a solid orange background to keep its white text readable in light mode.
- Updated package and executable versions to `1.177-13`.

## Validation

- All 12 existing JavaScript tests passed, including protection status and pixel animation checks.
- WebKit checks verified white button text/icons and zero pixel spacing in both themes, in native-pane and narrow layouts.
- Release CLI and GUI builds, packaged versions, embedded UI resources, and maintainer-script syntax were verified.

## Installation or upgrade

Download `obscura-simple_1.177-13_amd64.deb` and `SHA256SUMS`:

```sh
sha256sum -c SHA256SUMS
sudo apt install ./obscura-simple_1.177-13_amd64.deb
```

Close and reopen the GUI after upgrading. Package architecture: **amd64**, targeting Ubuntu 24.04 or a system with compatible dependencies.
