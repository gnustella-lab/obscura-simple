# Obscura Simple UI 1.177-14

## What's changed

- Increased the animated Connection background from five to eight rows, making the band 60% taller at the same window width.
- Kept square pixels without gaps, with a progressively denser pattern toward the bottom.
- Preserved the bottom-to-top reveal, cancellation behavior, and reduced-motion preferences.
- Updated the animation test to check row ordering across the entire grid.
- Updated package and executable versions to `1.177-14`.

## Validation

- All 12 existing JavaScript tests passed.
- WebKit rendering checks verified eight rows of gapless squares in native-pane and narrow layouts, alongside white orange-button text in both themes.
- Release CLI and GUI versions, packaged binaries, embedded UI resources, and maintainer-script syntax were verified.

## Installation or upgrade

Download `obscura-simple_1.177-14_amd64.deb` and `SHA256SUMS`:

```sh
sha256sum -c SHA256SUMS
sudo apt install ./obscura-simple_1.177-14_amd64.deb
```

Close and reopen the GUI after upgrading. Package architecture: **amd64**, targeting Ubuntu 24.04 or a system with compatible dependencies.
