# Obscura Simple UI 1.177-15

## What's changed

- Fixed the Connection pixel animation restarting every time the user returned from another tab.
- Navigation now changes visibility only; tunnel requests and status updates control the pixel fill.
- Connecting starts the bottom-to-top reveal, disconnecting or cancelling clears the fill, and reconnecting starts a fresh reveal.
- Removed the forced replay when reapplying the motion preference.
- Retained the eight-row, gapless background and white text on orange buttons in both themes.
- Updated package and executable versions to `1.177-15`.

## Validation

- All 15 JavaScript tests passed, including new regression coverage for tab navigation while connected, connecting, and disconnected; disconnect/reconnect after navigation; and reapplying the motion preference.
- WebKit checks verified that completed CSS animation objects are preserved across all tabs and a new reveal starts on reconnection, in native-pane and narrow layouts.
- Release executable versions, packaged binaries, embedded UI resources, and maintainer-script syntax were verified.

## Installation or upgrade

Download `obscura-simple_1.177-15_amd64.deb` and `SHA256SUMS`:

```sh
sha256sum -c SHA256SUMS
sudo apt install ./obscura-simple_1.177-15_amd64.deb
```

Close and reopen the GUI after upgrading. Package architecture: **amd64**, targeting Ubuntu 24.04 or a system with compatible dependencies.
