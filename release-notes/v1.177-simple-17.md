# Obscura Simple 1.177-17

This release returns Linux distribution to one functional Debian package. The
`.deb` contains the Simple CLI, privileged service and native GTK/WebKit GUI;
Flatpak is not required or produced.

## Download and install

Download `obscura-simple_1.177-17_amd64.deb` and `SHA256SUMS`, then verify and
install the single artifact:

```bash
sha256sum -c SHA256SUMS
sudo apt install ./obscura-simple_1.177-17_amd64.deb
sudo obscura-simple add-operator "$USER"
obscura-simple-gui
```

The package targets Ubuntu 24.04-compatible systems. It does not require
Flatpak, does not start or enable a VPN service during installation, and does
not modify the official Obscura service. Upgrade with the same `apt install`
command; close and reopen the GUI afterward so its version matches the service.

## Changes

- Removed the split GUI bundle and its build path from the release workflow.
- Restored the complete native GUI command bridge, including service restart,
  operator permissions, autostart and debug-bundle actions.
- Kept the dedicated Simple executable, service, group, IPC sockets, GTK/D-Bus
  identity, WebKit state, AppArmor profile and persistent state directories.
- Kept the shared `/run/obscura.lock`, acquired before firewall, tunnel and DNS
  initialization, so two VPN backends cannot control networking concurrently.
- Kept passive maintainer scripts and explicit unofficial-client branding.

## Verification scope

The CI job builds the single `.deb`, checks its payload and maintainer scripts,
runs the JavaScript/Rust tests, and tests isolated package installation and
reinstallation. The transaction helper accepts a previous `.deb` as a second
argument to exercise a real upgrade. No live VPN connection, host
firewall/VPN reconfiguration or kill-switch leak test is implied by a
successful build.

This is an independent community client, not an official Obscura release.
